# Sales-Dashboard-Using-Microsoft-Excel
1. Project Title / Headline
📈 Sales Performance Dashboard – Microsoft Excel
An interactive Excel dashboard developed to monitor and analyze sales executives' performance across multiple regions. The dashboard provides dynamic insights into sales achievements, target completion, and performance metrics using Pivot Tables, Pivot Charts, Slicers, and Excel formulas.

2. Project Overview
The Sales Performance Dashboard is built using Microsoft Excel to transform raw sales data into meaningful business insights. It enables users to evaluate sales performance, compare employees, monitor target achievement, and analyze regional sales through interactive visualizations.
The dashboard is designed to simplify business reporting and support data-driven decision-making with an easy-to-use and interactive interface.

3. Project Objectives
Monitor sales performance of individual sales executives.
Compare total sales across employees.
Track target achievement percentages.
Measure the gap between actual sales and targets.
Filter reports dynamically by city/region.
Provide quick business insights using interactive charts.

Chennai
Delhi

📊 Sales Executive Performance
Displays total sales achieved by each sales executive using Pivot Tables.

🎯 Target Achievement Analysis
Shows the percentage of sales targets achieved by each employee, making it easy to identify top performers.

📉 Away From Target Analysis
Displays the remaining percentage required for each employee to reach their assigned sales targets.

📊 Employee Sales Comparison
A horizontal bar chart comparing total sales across sales executives.

🥧 Target Hit Distribution
A pie chart illustrating the contribution of each sales executive toward overall target achievement.

📈 Performance Trend Analysis
A line chart visualizing the variation in employee performance and target completion percentages.
